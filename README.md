# Стерео

Свободная песочница по стереометрии. React, TypeScript, Three.js, KaTeX и Vite. Без аккаунтов, сервера и платных API.

## Запуск и проверка

- npm install
- npm run dev — локальный просмотр
- npm test — проверки геометрии (Node.js 22.18+ или 24)
- npm run build — сборка в dist

Для Vercel: команда сборки npm run build, папка результата dist. Публикация не выполнена.

## Фигуры

Куб, прямоугольный параллелепипед, прямая и наклонная треугольные призмы с равносторонним основанием, квадратная и треугольная пирамиды, цилиндр, конус и объединённый раздел «Шар и сфера». Внутри последнего переключаются тело и поверхность; теория, площадь и объём соответствуют выбранному варианту. У треугольной пирамиды основание равностороннее, вершина над его центром; она является правильным тетраэдром только при соответствующем отношении высоты к ребру.

Все фигуры имеют параметры и собственную теорию. Отображаются объём и площадь полной поверхности, для соответствующих фигур — площадь боковой поверхности. Сфера — поверхность, поэтому объём ей не приписывается; в теории приведена формула объёма ограниченного ею шара. Размеры в условных единицах.

## Сечения и части

Плоскость задаётся смещением, наклоном 0–180° и поворотом вокруг Y 0–360°. Для многогранников также доступны три точки на рёбрах. После выбора точки её можно сдвигать вдоль ребра. Три коллинеарные точки не задают плоскость.

Переключатель вспомогательных построений показывает следы плоскости в плоскостях пересечённых граней, продолжения рёбер и вспомогательные точки H. Очень удалённые пересечения опускаются с пояснением. Это одновременное отображение построений, без пошагового урока.

Для многогранников можно выделить одну из частей по сечению. Вычисляются объём, полная поверхность и доля исходного объёма. Исходная фигура остаётся полупрозрачным ориентиром. Режим «Тело по вершинам» строит выпуклую оболочку выбранных вершин; требуются минимум четыре некомпланарные точки. Так можно исследовать пирамиды внутри призм и многогранники, заданные перечислением вершин.

Сечение шара и сферы рассчитывается аналитически. Для сферы указана площадь круга, ограниченного окружностью сечения. Наклонные сечения цилиндра и конуса отображаются и измеряются по полигональному приближению с 96 сегментами; горизонтальные площади вычисляются точно. Три точки и вспомогательные построения доступны только для многогранников.

## Сочетания

Пять готовых конструкций:

- Конус и цилиндр с общим основанием и высотой.
- Цилиндр в параллелепипеде с квадратным основанием 2r × 2r и общей высотой.
- Шар в цилиндре: общий радиус, высота цилиндра 2r.
- Конус в шаре: вершина на сфере, радиус основания зависит от высоты; при h = R основание лежит в экваториальной плоскости.
- Два цилиндра: независимые отношения радиусов и высот.

Каждый компонент можно скрыть отдельно. Показаны их площади, объёмы и отношение объёмов. Размеры связаны геометрическими условиями. Это набор конструкций, а не произвольное объединение любых объектов. Сечения и развёртки в режиме сочетаний отключены.

## Сворачивание и разворачивание

У шести многогранников грани раскрываются вокруг общих рёбер. У цилиндра боковая поверхность разворачивается в прямоугольник шириной 2πr, у конуса — в сектор радиуса l = √(r² + h²). Основания раскрываются отдельно, оставаясь прикреплёнными в выбранной точке. Есть воспроизведение, пауза, обратное складывание, сброс и ручное раскрытие 0–100%.

В разделе «Шар и сфера» доступен режим «Лепестки глобуса»: 30 заострённых меридиональных лепестков расходятся в плоскую радиальную композицию и плавно собираются в сферическую оболочку. Есть сборка, пауза, обратное раскрытие, сброс и ручной прогресс сборки. Камера приближается при сборке. Цветовые полосы, швы и линии широт помогают видеть конструкцию. Это приближённая визуализация изготовления глобуса с искажением материала, а не точная изометрическая развёртка сферы. В промежуточных положениях анимация не проверяет столкновения граней. Швы раскрытия выбраны автоматически; редактирование дерева швов пока не предусмотрено.

## Жидкость

У цилиндра и конуса можно включить жидкость и изменять её уровень. Конус можно перевернуть вершиной вниз. При высоте заполнения f от полной высоты доля объёма жидкости равна f для цилиндра, f³ для перевёрнутого конуса и 1 − (1 − f)³ для конуса вершиной вверх.

## Проверки

npm test проверяет сохранение длин рёбер при раскрытии шести многогранников на пяти этапах, плоскостность конечных развёрток, возврат к собранной фигуре, площадь боковой поверхности цилиндра и конуса, соотношения объёмов и условия вписывания, сохранение объёма наклонной призмы при сдвиге основания. Для 30 лепестков проверяются совпадение швов в собранном состоянии, принадлежность точек сфере заданного радиуса, плоскостность и заострённость раскрытых лепестков, конечность координат промежуточных форм и суммарная площадь плоских лепестков.

## Хранение и ограничения

В localStorage сохраняются выбранная фигура и основные размеры a, b, h. Камера, точки сечений, сочетания и анимация между перезагрузками не сохраняются. При перекрытии проекций рёбер поверните модель перед выбором точки. Свободные точки внутри граней и их перетаскивание мышью пока не реализованы.

Математические шрифты KaTeX входят в сборку. Шрифт интерфейса загружается из Google Fonts с системным запасным вариантом.


## Оформление и компоновка

Приложение занимает высоту окна без общей прокрутки страницы. Размер сцены остаётся постоянным при смене фигур и режимов; каталог и правая панель прокручиваются внутри собственных областей. На экранах до 680 px параметры открываются отдельной панелью поверх сцены. Основной акцент #5946FF, теория и формулы #9B2C33, точечные акценты и сечения #FF3A00. Исходный логотип скопирован в assets/math_logo.png и включается в сборку Vite.

## Светлая и тёмная темы

Переключатель находится справа в шапке. Выбор сохраняется в localStorage; при первом открытии учитывается системная тема. Для тёмной темы настроены интерфейс, формулы, сетка, материалы моделей, сочетания и развёртки. Основные обозначения вершин чёрные; в тёмной теме добавлен светлый контур. Сочетания вынесены над каталогом. Нажатие на доступный инструмент, вид или фигуру выходит из развёртки и останавливает её анимацию. Под формулой наклонной призмы объяснён знак суммы ∑.

## Разделы лаборатории

В шапке находятся «Стереометрия» и «Графики функций». В нижнем колонтитуле оставлена только «Открытая лаборатория». При переключении состояние обоих разделов сохраняется в текущем сеансе; 3D-рендеринг приостанавливается, пока открыт раздел графиков.

Графики ориентированы на прототипы ЕГЭ №12: прямая, парабола, гипербола k/x, a√x, a^x и log_a x. Шесть пресетов добавляют готовые формулы с независимыми коэффициентами. Внизу расположен свёрнутый раздел «Калькулятор и своя функция»: добавление пустой карточки и редактор MathLive с блоками дроби, степени, корня, логарифма с основанием, модуля и скобок, а также вкладкой чисел. Тригонометрия и переключатель радиан/градусов удалены. До шести формул; у каждой свои a, b, c, k. Числовой ввод и ползунки, скрытие/удаление графиков, панорамирование и масштабирование сохранены.

Инструменты исследования: f(x) для заданного аргумента с точкой и проекциями; пересечения двух функций в заданном интервале с маркерами A, B, …; восстановление функций по точкам. Прямая восстанавливается по двум точкам, парабола — по трём; k/x, a√x, a^x, log_a x — по одной допустимой точке при известном виде зависимости. В правой панели для каждого вида есть собственная теория с параметрами, областью определения и приёмами чтения графика. Шрифты редактора находятся в public/mathlive/fonts; для рендера и вычислений внешние API не нужны.

Пересечения вычисляются численно: проверка изменения знака, бисекция и поиск локальных минимумов |f−g| для касаний. Неопределённые точки и ложные пересечения на полюсах отбрасываются проверкой остатка. Поиск ограничен выбранным интервалом и дискретизацией; он не гарантирует нахождение всех корней произвольной быстро осциллирующей функции. Совпадающие на проверенных точках графики отмечаются отдельно. Разрывы при рисовании определяются численно; символьного доказательства свойств нет. Коэффициенты, графики и вид сохраняются при переключении разделов, но не после перезагрузки страницы.

Дополнительно npm test проверяет приоритет операций, неявное умножение, функции и области определения, десятичную запятую и некорректные выражения.

## Параметры отдельных функций и постоянная привязка

У каждой карточки свои коэффициенты a/b/c/k. Правая панель подписана именем выбранной функции и разделена на «Параметры» и «Исследование». При переключении карточки поля пересоздаются для её параметров, поэтому незавершённый ввод не переносится на другую функцию. Отдельные масштабы и сдвиги по X/Y удалены: график строится непосредственно по введённой формуле. Коэффициенты, аргумент инструмента значения и границы поиска пересечений ограничены диапазоном −25…25. Аргумент меняется с шагом 1; есть кнопки −1/+1. У всех ползунков стрелки меняют значение на объявленный шаг.

Привязка координатного индикатора к целочисленным узлам включена постоянно. Флажка отключения и обхода через Shift нет. В режиме пересечений доступны также найденные точки пересечения функций. Радиус до 6 пикселей, на отдалённом масштабе ограничен долей единичного отрезка. Панорамирование остаётся свободным.
